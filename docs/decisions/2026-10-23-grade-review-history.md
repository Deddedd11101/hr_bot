# Решение

Новые оценки фиксируют фактические уровни без персональной цели. Новая оценка
не копирует значения предыдущей. Неоценённый навык отличается от явного нуля.
Каталог замораживается при создании черновика; финальный снимок неизменяем.

Сравнение использует стабильный ID навыка, семантическую ревизию и шкалу.
Изменённые, добавленные, удалённые и неоценённые навыки показываются отдельно,
без выдуманной динамики. Редакционная правка названия не меняет ревизию.

Решение о кадровом грейде принимает человек независимо от завершения оценки.
Решения сохраняются отдельной историей с комментарием. Повторная оценка сама
по себе не повышает грейд. Старые финальные снимки и поля целей сохраняются
для совместимости, но не управляют новым процессом.

Импорт шаблона требует предварительного просмотра и совпадения fingerprint.
Импорт не удаляет глобальные навыки или историю; состав специализации явный.
Персональные оценки из XLSX не применяются автоматически вместе с шаблоном.
Без известной даты исходного ревью нельзя выдавать дату импорта за дату оценки.
