# Подтверждение рабочей почты сотрудника

Для сотрудников Telegram username остаётся только подсказкой для поиска карточки. Доступ
даёт numeric Telegram ID, подтверждённый кодом, отправленным на уникальную рабочую
почту в домене `ze.studio`. Ранее привязанные сотрудники также проходят проверку.
Кандидатский `/start` сохраняет прежнее поведение.

Отправитель — существующий ящик `info@ze.studio` в Яндекс Почте. Используем
SMTP SSL и отдельный пароль приложения, не основной пароль ящика. Код хранится
как HMAC; без настроенного SMTP и включения отдельного feature flag существующий
stage contract не меняется. Если проверка включена, ошибка почты закрывает доступ,
а не возвращает вход по username.

Альтернатива «сопоставлять только по Telegram-нику» отвергнута: ник можно изменить
или передать другому пользователю. Автоматическая перепривязка уже подтверждённого
numeric ID также не допускается; новый аккаунт проходит операторский reset.
